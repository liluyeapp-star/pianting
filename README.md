# 偏听则明 · Pianting

![偏听则明：这期，我只听 TA。](assets/banner.svg)

**这期，我只听 TA。**

一场对谈里，你可能只想听其中一个人。
偏听则明帮你找出 TA 的发言，按原顺序剪出原声，做成能放进手机播客应用的版本。

**v0.1.0 中文试用版 · 飞书妙记优先 · 保留原声 · 可选个人 RSS**

这是给能运行本地脚本的 AI 助手使用的 **Skill + 工具脚本**。首次使用需要配置环境和飞书；它还不是一个打开网页就能用的在线服务。

## 你可以怎么说

```text
用「偏听则明」处理这期：[节目链接或本地文件]
只保留：[人物姓名]
先给我试听和完整 MP3。
```

需要手机收听时再补一句：

```text
把这期加入我自己的个人 RSS，沿用原来的订阅。
```

## 能做什么

- **找到音频**：本地文件、公开 RSS、音频直链，以及小宇宙公开免费单集网页。
- **区分人物**：用飞书妙记的逐字稿、说话人标签和时间戳，结合实际发言确认目标人物。
- **剪出原声**：保留完整回答与原顺序，输出完整版、短试听和原音频时间映射。
- **手机继续听**：可选生成个人 RSS，部署到自己的空间，再添加到苹果播客等支持 RSS 的应用。

```mermaid
flowchart LR
  A[链接或音频文件] --> B[取得公开音频]
  B --> C[飞书转写与说话人标签]
  C --> D[确认人物和校对边界]
  D --> E[原声 MP3 与试听]
  E --> F[可选：个人 RSS]
```

**小宇宙链接不必依赖 API 才能取得音频。** 部分公开单集的网页 HTML 已带有公开音频直链，本项目只解析这份匿名 HTML，并核实免费/公开标记。网页没有可用音源就停止，不调用 API，不使用登录态或第三方代理绕行。详见 [音源机制](skills/pianting/references/音源说明.md)。

## 五分钟看懂安装

### 需要哪些工具、账号和基础设施？

| 环节 | 使用什么 | 是否必需 |
| --- | --- | --- |
| 运行与剪辑 | 能执行本地脚本的 AI 助手、Python、FFmpeg | 必需；在自己的电脑运行 |
| 从小宇宙公开网页取得音频 | 本项目自带的下载脚本 | 不需要小宇宙账号、API 或下载插件 |
| 转写与认人 | 飞书妙记；自动操作另需已授权的 lark-cli | 本版默认路线；也可以提供已导出的带说话人和时间戳的飞书 TXT |
| 手机持续订阅 | 在线存放 MP3 和 RSS 的空间 | 可选；只要本地 MP3 就不需要 |
| 已跑通的托管方案 | 自己的 Cloudflare 账号、Pages 项目；命令行部署需 Node.js / Wrangler | 仅选择这条手机订阅路线时需要 |
| 手机收听 | 苹果播客等支持个人 RSS 的应用 | 订阅自己的地址，无需把节目提交到公开目录 |

**Cloudflare 是可选的托管基础设施。** 它让音频和 RSS 在电脑关机后仍可访问；飞书负责转写，本地脚本负责剪辑，GitHub 存放工具源码。项目不提供共享托管账号，也不会自动替你注册、付费或开通云服务。

只想先试剪辑：完成下面的本地安装和飞书配置即可。想像普通播客一样在手机里持续听：[Cloudflare 手机订阅完整教程](skills/pianting/references/手机订阅.md) 包括账号准备、生成 RSS、部署、首次订阅和后续更新。

Cloudflare 免费方案有额度和单文件限制，本项目还使用 Worker 支持音频拖动，不能把它理解成无限免费的音频服务。具体限制与官方依据见上述教程。

### 本地安装

先[下载源码](https://github.com/liluyeapp-star/pianting/archive/refs/heads/main.zip)或克隆这个仓库，进入仓库根目录（其中有 `requirements.txt` 和 `doctor.py`）。需要 Python 3.9+、FFmpeg，以及支持读取 Skill 和运行脚本的 AI 助手。

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 doctor.py
```

Windows 的虚拟环境激活命令不同；v0.1 实际验证环境为 macOS，Windows/Linux 的完整流程尚未验证。

FFmpeg 需另行安装，并确保 `ffmpeg`、`ffprobe` 在 PATH 中。macOS 已安装 Homebrew 时可运行 `brew install ffmpeg`。可参考 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)。

将技能安装到你的助手：

```bash
# Codex
python3 install.py --dest ~/.codex/skills

# Claude Code（二选一，也可以都安装）
python3 install.py --dest ~/.claude/skills
```

安装器只复制 `skills/pianting/`，遇到已存在目录会停止，避免覆盖你的版本。然后让助手使用 `$pianting` 或 `/pianting`；具体发现/调用方式以所用助手为准。告诉助手使用刚创建的 `.venv` Python，或在启动助手前激活环境。

**飞书首次授权**按 [飞书配置](skills/pianting/references/飞书配置.md) 完成。没有配置 CLI 时，也可以手动上传到妙记并提供带说话人和时间戳的 TXT。飞书账号可用权限、额度和组织策略会影响自动化，不保证任意个人账号开箱即用。

## 先跑一个不需要账号的演示

```bash
python3 examples/demo.py --output-dir ./work/demo
```

这个演示生成两种不同音调代表两位说话人，再只保留其中一种，跑通解析、剪切和映射。它**不是语音识别质量演示**，也不访问网络。结果在 `work/demo/out/`。

真实流程及逐步命令见 [上手示例](docs/上手示例.md)。

## 已验证到哪里

已有真实中文双人访谈剪辑案例：约 79 分钟 → 约 45 分钟；原声文件及手机 RSS 播放已验证。该案例结合了本地识别、飞书交叉核对与边界修订，不能据此宣称“飞书自动剪辑全程无需校对”。

公开版另验证了匿名单集网页完整音频下载、飞书现有妙记导出、离线剪辑测试和个人 RSS 构建。新版渲染器也已对真实素材重跑：输出 45 分 20 秒，完整解码及时间映射校验通过。

第二个真实案例为三人对谈中保留一位嘉宾：约 89 分钟 → 59 分 23 秒。用公开版下载器取得免费网页音频，飞书包装器完成新上传、创建妙记及导出，再结合本地音频识别校对切口。个人 RSS 已增加第二集，验证旧集保留、新集完整下载一致性和分段播放响应。托管发生在用户自己的 Cloudflare 账号，不是 GitHub 自带服务。详细范围见 [验证记录](docs/验证记录.md)；仍未在陌生用户的新账号上完整验收。

## 你需要知道的限制

- **说话人标签会出错，时间戳也有误差。** 自动清单只是粗剪；准确剪辑需要边界校对。无法听检时会标为粗剪。
- **同时说话无法靠普通剪切干净拆开。** 为保留目标人物，可能留下别人的短附和。
- 小宇宙支持限公开免费单集网页，页面结构变化可能失效；不支持付费、私密或需登录音源。
- 第一版优先中文、飞书、双人对谈。海外转写服务与多平台安装支持尚未接入。
- 个人 RSS 是可选功能，由你自己的存储托管；长随机链接不是账号鉴权。小宇宙内的私人订阅导入尚未验证。
- 工具和源码开源，不意味着原节目的音频版权也开放。请处理你有权处理的材料，不默认公开再发布他人的精剪节目。
