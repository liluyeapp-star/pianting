# v0.1.0 验证记录

日期：2026-09-16。首个中文试用版，验证环境为 macOS / Python 3.9 / Node.js，配有 FFmpeg 与已授权 lark-cli。

## 真实素材验证

- 用户指定的一期小宇宙公开免费单集：只请求匿名 HTML，取得公开媒体直链；完整下载 76,560,361 字节，媒体时长约 78 分 49 秒，大小与公开页面声明一致，FFmpeg 完整解码通过。
- 新包装器以 resume 复用用户已有妙记，成功导出 TXT；解析得到指定说话人的粗清单。没有重复上传或创建。
- 既有真实剪辑约 79 分钟 → 45 分钟，涉及本地识别、飞书交叉核对和边界修订。它不是“纯飞书全自动准确剪辑”的证据。
- 既有个人 RSS 在线验证过完整音频一致性、HEAD 长度，以及开头/中段/末段 Range 206。公开包的 RSS 构建器另做了离线安装与构建检查，未替陌生用户开通托管账号。

不随公开仓库附带真实音频、逐字稿、妙记链接、账号状态或个人 RSS。

- 新版流式渲染器已用上述完整原音频和既有校订清单重跑，输出 2720.172 秒；完整解码通过，保留片段加间隔与时间映射终点一致。

## 2026-09-16 第二个真实案例补充

- 三人对谈原音频 5315.9 秒、86,052,654 字节，通过同一匿名 HTML 下载器取得；完整解码通过。
- 公开版飞书包装器在已配置的用户账号下完成新文件上传、妙记创建及 TXT 导出。首次运行遇到本机授权缓存写入被沙箱拒绝，确认失败发生在上传前，再取得所需本地权限后继续；没有重复创建妙记。
- 飞书说话人标签与本地音频识别交叉核对，对 19 个争议或碎片窗口做额外音频转写对齐，修正切口后输出 120 段、3562.904 秒。并非逐秒人工听检，重叠附和仍可能存在。
- 128 kbps 完整版与 56 kbps 单声道手机版均通过完整解码和时长核验；手机版约 24.94 MB，符合 Pages 单文件限制。
- 在既有 Cloudflare 个人订阅中增加第二集，保留原路径和单集 GUID。线上 RSS 两集、新集 HEAD、首/中/末段 Range 206、完整下载 SHA256 与旧集分段访问均通过。手机端添加订阅此前已验证，本次验证的是更新后的线上文件及协议响应。
- 托管使用实际个人资料库的更新/发布脚本；公开包提供 RSS 构建器和 Worker 模板，云端部署按教程用 Wrangler 完成。不是从空白账号开始的一键自动开通测试。

## 离线检查项目

- 匿名音源：公开/免费判断、错集拒绝、付费/私密停止、API与鉴权媒体拒绝、重定向不得进入 API、私网拒绝、RSS 唯一选集。
- 飞书：已上传素材复用、创建中断不重复、上传中断不盲重传、同路径换文件识别、已有妙记续取、认证失败恢复。
- 音频：用不同频率音调模拟两人交替发言，验证输出只含选中频率、总时长和原时间映射；重叠清单被拒绝。
- RSS：多集保留、路径与 GUID 稳定、超限不写坏库、路径输入拒绝。
- Worker：HEAD、完整 GET、开头/后段/suffix Range、416、If-Range 失配、非媒体透传。
- 独立安装：复制到空技能目录后能运行演示和 RSS 构建，内部文档链接可解析。
