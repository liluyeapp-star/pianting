# 从一段对谈到只听一个人

先按首页安装依赖并配置飞书。以下在仓库根目录、已激活的 Python 环境中运行；使用 AI 助手时可以把这些工作直接交给它。所有 work/out 都是用户本地数据，不会随仓库发布。

## 1. 提供原音频

本地文件可以直接使用。如果提供公开小宇宙单集链接：

```bash
python3 skills/pianting/scripts/fetch_audio.py "<实际公开单集网页URL>" --output-dir ./work/episode-001/source
```

检查输出的实际文件名和格式，不要假定一定是 MP3。音源边界见 [音源说明](../skills/pianting/references/音源说明.md)。

## 2. 飞书转写

```bash
python3 skills/pianting/scripts/feishu_transcribe.py transcribe "<本地音频路径>" \
  --title "节目名称" --work-dir ./work/episode-001/feishu \
  --output ./work/episode-001/transcript.txt
```

已有妙记可改用 `resume "<妙记链接>"`，不重复上传。也可以直接使用手动导出的 TXT。

## 3. 确认人物和片段

原时长可用以下命令读取：

```bash
ffprobe -v error -show_entries format=duration -of default=nw=1:nk=1 "<本地音频路径>"
```

结合介绍和实际发言确认目标标签，然后生成粗清单：

```bash
python3 skills/pianting/scripts/segments_from_feishu.py \
  --transcript ./work/episode-001/transcript.txt --speaker "<确认的标签>" \
  --duration <原音频秒数> --output ./work/episode-001/keep-coarse.json
```

按 [剪辑校对](../skills/pianting/references/剪辑校对.md) 修订切口，保存 `keep-reviewed.json`。此步骤需要音频判断，不能只是改文件名就称为已校对。

## 4. 渲染

```bash
python3 skills/pianting/scripts/render_guest.py --source "<本地音频路径>" \
  --segments ./work/episode-001/keep-reviewed.json --output-dir ./out/episode-001 \
  --work-dir ./work/episode-001 --title "节目名称｜目标人物原声版"
```

输出 `guest.mp3`、`preview.mp3`、`时间映射.csv`。完整解码检查：

```bash
ffmpeg -v error -i ./out/episode-001/guest.mp3 -f null -
```

程序检查之外，还要核对实际试听范围，注明未检查的边界。

## 5. 可选手机订阅

按 [手机订阅](../skills/pianting/references/手机订阅.md) 为自己建立 RSS。先保留高音质原文件，再根据托管限制生成手机版。不会复用项目作者或其他用户的账号。
