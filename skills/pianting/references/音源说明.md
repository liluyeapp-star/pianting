# 音源获取：公开网页也能提供音频

偏听则明 v0.1 支持本地文件、明确指定单集的公开 RSS、媒体直链，以及小宇宙公开免费单集网页。小宇宙网页支持属于尽力支持：网站可随时调整 HTML，不能承诺所有链接都能下载。

## 小宇宙这条路线做了什么

1. 只接受用户给出的 `/episode/<单集ID>` 网页。
2. 不带 Cookie、账号或 token 读取 HTML，不执行 JavaScript，不启动浏览器或拦截请求。
3. 在页面内嵌的 `__NEXT_DATA__` 中核对单集 ID，并同时要求 `isPrivateMedia=false`、`payType=FREE`、`media.source.mode=PUBLIC`。
4. 下载这份 HTML 已经提供的公开音频地址。核对大小、保存 SHA256；失败时不把残片冒充完整文件。

这是独立实现，不依赖第三方下载插件。**读取匿名网页里的静态数据，不是调用小宇宙 API。** 本工具没有平台账号功能，也不读取官方字幕接口。

```bash
python3 skills/pianting/scripts/fetch_audio.py \
  "https://www.xiaoyuzhoufm.com/episode/公开单集ID" \
  --output-dir ./work/episode-001/source
```

将上述示例中的整个链接换成实际公开单集链接。成功后会有 `source.m4a`（或原格式）与 `source.json`；实际后缀以输出为准。

若只想查看是否有可用音源，加 `--metadata-only`，请使用独立输出目录，避免覆盖已有下载记录。

## 停止条件

- 403、需登录、付费、私密、公开性标记缺失、仅有试听或数据结构改变：停止；可另找节目官网或公开 RSS，或使用合法取得的本地文件。
- 不使用匿名 API、登录态、设备 ID、账号刷新、浏览器网络 hook、第三方代理解析站或加密媒体解密作为回退。
- 工具不扫描节目列表，不自动抓取账号订阅。平台可改变访问规则；不宣称“匿名就是零风险”。

## RSS

```bash
python3 skills/pianting/scripts/fetch_audio.py "https://example.org/feed.xml" \
  --episode "准确单集标题或 GUID" --output-dir ./work/episode-001/source
```

RSS 有多集时必须唯一选择，程序会给出少量候选标题。URL 来自用户或官方公开渠道；可公开收听不等于有权公开再发布，剪辑用于用户有权处理的素材，不向公共目录默认投稿。

## 调研依据与实测范围

2026-09-16 独立实现已对一份用户指定的公开免费单集完整下载，核对页面大小和时长并完整解码通过。没有调用小宇宙 API、没有读取账号状态；真实节目音频不包含在此仓库。

技术参考（只阅读思路，没有复制其代码）：
