# 飞书妙记配置

「偏听则明」用飞书妙记取得带说话人标签和时间戳的逐字稿。它只处理你合法取得并放在电脑上的音频或视频；不会下载节目，也不会删除你的本地文件、云空间源文件或妙记。

## 第一次配置

1. 安装 [LarkSuite CLI](https://github.com/larksuite/cli)，并确认终端能运行 `lark-cli --help`。
2. 运行 `lark-cli config init --new`，按命令提示完成应用配置。
3. 用用户身份登录并授权。可先按最小业务范围授权 Drive；如果命令明确报告缺少权限，按错误中给出的 scope 或提示补充授权：

   ```bash
   lark-cli auth login --domain drive --no-wait --json
   ```

   妙记创建和读取也需要应用已经具备对应的 Minutes 权限。不同飞书组织的可用权限会不同，以 CLI 返回的 `missing_scopes` 和 `hint` 为准；本工具不会替你登录、申请或扩大权限。

4. 检查登录是否有效：

   ```bash
   lark-cli auth status --json --verify
   ```

创建妙记会把原始文件上传到你自己的飞书云空间，并在其中生成一条妙记。飞书支持的格式包括 mp3、m4a、wav、aac、ogg、mp4 等；原文件不超过 6GB、时长不超过 6 小时。

## 自动导出逐字稿

```bash
python3 skills/pianting/scripts/feishu_transcribe.py \
  transcribe ./episode.mp3 \
  --title "节目名称：嘉宾原声" \
  --work-dir ./work/episode-001 \
  --output ./out/episode-001-feishu.txt
```

`--work-dir` 是断点状态目录，里面会保存 `file_token` 和 `minute_token`。请为每一期使用不同目录，也不要在剪辑完成前删除它。`--output` 是最终导出的 TXT 路径，必须明确给出。

如果上传或转写中断，先检查 `--work-dir` 内的状态文件。已保存 `file_token` 后，脚本不会再次上传同一文件；已保存 `minute_token` 后，也不会再次创建妙记。脚本同时保存音频内容的指纹：即使文件路径相同，只要内容换过，也会拒绝复用旧状态。

若云空间上传请求中断且没有返回 `file_token`，服务器是否已收到文件无法确定，脚本会停止，避免重复上传。请在飞书云空间找到该文件并取得其 `file_token`，再用下面的命令继续创建妙记：

```bash
python3 skills/pianting/scripts/feishu_transcribe.py \
  resume-upload ./episode.mp3 \
  --file-token "已确认的file_token" \
  --work-dir ./work/episode-001 \
  --output ./out/episode-001-feishu.txt
```

若妙记创建请求中断且服务器是否接受请求无法确定，脚本同样会停止，避免重复创建；到飞书妙记找到该条目后，再执行：

```bash
python3 skills/pianting/scripts/feishu_transcribe.py \
  resume "https://你的域名.feishu.cn/minutes/妙记token" \
  --work-dir ./work/episode-001 \
  --output ./out/episode-001-feishu.txt
```

## 不使用 CLI 的替代路径

也可以手动把本地音视频上传到飞书妙记，等待它生成文字记录，在妙记页面导出带说话人和时间戳的 TXT 文件。随后直接把 TXT 交给 `segments_from_feishu.py`：

```bash
python3 skills/pianting/scripts/segments_from_feishu.py \
  --transcript ./out/episode-001-feishu.txt \
  --speaker "Speaker 2" \
  --duration 3600 \
  --output ./work/episode-001/segments-coarse.json
```

飞书的说话人标签和切分边界需要结合原音频确认。多人抢话、笑声和短附和可能使标签或结束时间有误差；生成原声精剪前，必须审核片段边界，不能把自动结果当作最终剪辑清单。
